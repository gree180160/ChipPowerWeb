通用组件测试 - LoadingButton / Pagination / PageLoading

使用纯 SVG + CSS 动画,不依赖 FontAwesome

1 LoadingButton 通用按钮

点击任意按钮,观察 loading 旋转图标(SVG)+ 文字变化。图标颜色随按钮配色走。

2 Pagination 分页控件

当前页: {{ currentPage }}

每页: {{ pageSize }} 条,总: {{ totalItems }} 条,共 {{ Math.ceil(totalItems / pageSize) }} 页

支持:首页 / 上一页 / 页码 / 下一页 / 尾页 / 跳转输入框

3 PageLoading 页面刷新 loading

点击后整个页面被半透明遮罩覆盖,中央显示旋转图标和文字。

这是一个局部容器(相对定位)
